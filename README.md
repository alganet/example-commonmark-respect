# Validating Markdown Structures

This is an example of using Respect\Validation and League\Commonmark
to parse and validate markdown document structure and contents.

It's design to showcase Respect\Validation composition features, and
it is presented in three equivalent files:

 - rawmessages.php - Just the validator composition.
 - expressionbuilding.php - Validator composition + message shaping.
 - expressionzilla.php - The whole thing in a single chain.

These examples are illustrative and intended for educational purposes
only.
